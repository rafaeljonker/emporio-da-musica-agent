# Backend

The Python package `emporio` (uv project): four bounded contexts (`catalog`, `orders`, `policies`, `support`), each split into `domain/`, `application/` and `infrastructure/`, plus the web `api/` and the composition roots.

- `make check` (from the repo root): lint, types, import contracts and tests.
