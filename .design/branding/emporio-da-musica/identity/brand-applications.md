# Brand Applications

> Phase: identity | Brand: emporio-da-musica | Generated: 2026-11-05

---

Mobile-first: every surface is designed at phone width first (customers arrive from a WhatsApp link). UI copy in pt-BR, from [voice-and-tone.md](../strategy/voice-and-tone.md). No emoji in any brand copy.

## 1. Demo Login Screen

- **Canvas:** cream with faint paper grain. Primary wordmark (Direction A) centered top, walnut.
- **Headline (Fraunces 500–600):** "Entra aí pra conversar com a Empório"
- **Tagline (Fraunces italic, small, walnut muted):** "A verdade de quem toca."
- **Form on a spruce card:** e-mail and senha fields on paper-white, walnut labels above fields (not placeholder-only).
- **CTA:** full-width terracotta button "Entrar", cream label.
- **Demo note:** a small walnut-muted line stating it is a demo, e.g. "Ambiente de demonstração. Use as credenciais do case."
- **Error:** oxblood text + alert icon under the form: "E-mail ou senha não bateram. Confere e tenta de novo."
- **Feel:** opening the shop door, not logging into a bank.

## 2. Warm-up Screen (GPU waking up)

Honesty is the brand, so the wait is explained, not disguised.

- **Headline (Fraunces):** "Afinando o atendimento"
- **Explanation (Source Sans 3):** "O assistente roda num servidor que desliga quando ninguém está usando, e ligar de novo leva cerca de {N} segundos. Já já ele tá pronto."
- **Stages:** a short vertical list, each with a state icon (done check in moss, current with a subtle honey marker, pending in walnut muted). Suggested labels: "Ligando a GPU", "Carregando o modelo", "Pronto pra conversar".
- **Elapsed time:** tabular figures, e.g. "Esperando há 42 s". Real time, counting up.
- **No progress bar**, no fake percentage. The only motion is the logo ring breathing slowly (disabled under reduced motion).
- **Illustration:** one line drawing of tuning pegs.
- **Long wait / failure:** plain, blame-free copy with a terracotta "Tentar de novo" button.
- **Accessibility:** stage changes announced politely to screen readers; the timer is not announced every second.

## 3. Chat

- **Header:** spruce bar with the honey avatar (logo icon), "Assistente da Empório" in Source Sans 3 semibold, and a small walnut-muted subline ("assistente virtual da loja"), so nobody mistakes it for a person.
- **Background:** cream.
- **Agent bubbles:** spruce, walnut text, arriving **sequentially** (1–3 per reply) with a short natural delay between them. Consecutive bubbles from the same sender group tightly; avatar shown once per group.
- **User bubbles:** walnut with cream text, right-aligned.
- **Typing indicator:** spruce bubble with three honey dots, gentle pulse; screen-reader text "O assistente está digitando". Static dots under reduced motion.
- **Text only:** bubbles follow chat style rules (no markdown, no lists). Prices appear as plain sentences in Source Sans 3; no product grids. One exception added by the 2026-11-05 refine: a single honest ProductCard ("Na medida pro seu nível") when the agent recommends a specific instrument, per patterns/components.
- **Composer:** paper-white input with walnut text, placeholder "Escreve sua mensagem"; terracotta circular send button with cream icon and an accessible label "Enviar".
- **Empty state:** small line illustration + "Pergunta de preço, estoque, entrega ou qual instrumento combina com você. Pode mandar."
- **Error in thread:** inline walnut-muted note with retry link: "Perdi o fio da conversa aqui. Manda de novo?"

## 4. "Conversar como…" Customer Selector

- A demo control, so it should look like a tool, not like content: compact selector in the header area or a sheet, label "Conversar como…".
- Options as spruce chips/rows with the customer's first name in Source Sans 3 semibold and one walnut-muted line of context (e.g. city or order).
- Selected state: walnut outline + check icon + honey left marker (never color alone).
- Switching customer resets the thread with a quiet divider line in the chat: "Agora conversando como {nome}".

## 5. Assistant Avatar and Small Marks

- **Avatar:** soundhole ring + accent on a honey disc. No human name, no face. Used in chat header and beside first bubble of each agent group.
- **Favicon / app icon:** same icon, simplified (no rosette line) at 16 px.
- **WhatsApp profile image:** the icon on honey with comfortable padding for the circular crop.

## 6. Beyond the POC (direction only)

- **Store window / paper bag:** primary wordmark in walnut on kraft or cream.
- **Instagram:** own photos (hands, wood, counter) with Fraunces lines like "Às vezes, o mais barato resolve." on cream plates; no sale banners.
