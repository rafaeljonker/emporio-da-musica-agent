# Stack

Declared stack for the workspace (greenfield: the frontend is created in phase 5 of the project plan).

| Layer | Choice |
|---|---|
| Framework | Vite + React + TypeScript |
| Styling | Tailwind CSS v4 (CSS-first config, CSS custom properties) |
| Component library | shadcn/ui (Radix primitives) |
| Icons | lucide-react (ISC) |
| Fonts | Fraunces + Source Sans 3 via Fontsource (self-hosted, SIL OFL 1.1) |
| Location | `frontend/` (monorepo; the Python backend lives in `backend/`) |
| Accessibility target | WCAG 2.2 AA |

No existing tokens or components, so the system strategy is `generate`.
